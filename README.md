# ☕ Café Triple Peaks

Uma página web moderna e aconchegante para uma cafeteria temática localizada dentro de uma biblioteca. O projeto foi desenvolvido com foco em design limpo, boa experiência do usuário e semântica HTML.

---

## 🚀 O que tem no projeto? (Funcionalidades)

- **Apresentação da Cafeteria:** Seção principal com informações sobre o ambiente, horário de funcionamento e localização.
- **Seção de Receitas:** Espaço dedicado a tutoriais em vídeo de preparo de café (como Aeropress e Prensa Francesa) incorporados diretamente do YouTube.
- **Formulário de Reserva:** Um formulário completo para que os clientes possam reservar uma mesa informando nome, quantidade de convidados, data/hora e e-mail, além de validações básicas como campos obrigatórios e aceite de termos.
- **Rodapé com Redes Sociais:** Links para contato e redes sociais da cafeteria.
- **Navegação Interna:** Links rápidos no menu superior para rolar suavemente até as seções da página.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Utilizado para estruturar todo o conteúdo de forma semântica (tags como `<header>`, `<main>`, `<section>`, `<footer>`, `<form>`).
- **CSS3:** Responsável por toda a estilização visual, tipografia (fontes do Google Fonts), organização dos elementos e responsividade da página.
- **IFrames:** Para a integração dos vídeos de receitas.

---

## 📂 Como executar o projeto

Basta clonar este repositório ou baixar os arquivos e abrir o arquivo `index.html` diretamente em qualquer navegador web de sua preferência.
